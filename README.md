<td width="50%" valign="top">

<h3>🛡️ ProvGuard</h3>

<b>Reducing prompt-injection detector over-defense</b>

Research framework for selecting provenance-matched hard negatives that reduce false positives on benign prompts resembling attacks.

Five-seed experiments reduced external hard-benign FPR from <b>20.67% → 4.23%</b> while maintaining approximately <b>98% IID F1 and attack recall</b>.

<h3>🔐 PrivToken-ReID</h3>

<b>Privacy-preserving person re-identification</b>

Research into discrete latent representations that preserve information useful for person retrieval while making intercepted representations harder to reconstruct visually.

The system combines vector quantization, noisy latent tokens, part-based ReID features, reconstruction attackers, and privacy–utility evaluation.

<h3>🔍 Context-Differential Hallucination Detection</h3>

<b>Unsupervised token-level RAG hallucination signals</b>

Investigating whether changes between context-conditioned and context-free model distributions can reveal unsupported generation.

The framework combines entropy, information gain, KL divergence, confidence shifts, temporal aggregation, ablations, and cross-domain evaluation.
